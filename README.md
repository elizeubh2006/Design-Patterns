# Design Patterns em C# .NET 8.0

Este repositório é uma contribuição para programadores iniciantes, com exemplos realistas dos design patterns implementados em C# .NET 8.0.

## Visão Geral

A versão 1.0 deste repositório inclui os seguintes design patterns:
•  Abstract Factory

•  Chain of Responsibility

•  Factory Method

•  Observer

•  Singleton

•  Visitor


Os demais patterns estão em construção, mas contribuições são bem-vindas, seguindo a única regra de dar exemplos realistas (evitar exemplos de animais, árvores ou situações que nunca ocorreriam em sistemas).

## Documentação

Para mais informações sobre os design patterns, consulte a documentação oficial do .NET e outros recursos de aprendizado.
